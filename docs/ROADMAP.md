# Development Roadmap

The project is developed in small milestones. A milestone is not complete until it runs and has been tested.

## Phase 0: Foundation
- [x] Create repository structure.
- [x] Add initial Godot project configuration.
- [x] Record the current GDD and story foundation.
- [ ] Open project in the target Godot version.
- [ ] Confirm the project imports without errors.

## Phase 1: Movement prototype
- [ ] Create a test scene.
- [ ] Add a temporary player sprite.
- [ ] Implement four-direction movement.
- [ ] Add camera follow.
- [ ] Test keyboard controls.
- [ ] Check performance on the target laptop.

## Phase 2: Interaction prototype
- [ ] Add one NPC.
- [ ] Detect interaction range.
- [ ] Add an interaction prompt.
- [ ] Display dialogue.
- [ ] Add a simple quest flag.

## Phase 3: First playable slice
- [ ] Build one compact outdoor location.
- [ ] Add collision and basic navigation boundaries.
- [ ] Add a small daily activity.
- [ ] Add one short NPC quest.
- [ ] Add save/load only after the basic loop is stable.

## Phase 4: Core systems
- [ ] Time and day progression.
- [ ] NPC schedules.
- [ ] Relationship values and event gates.
- [ ] Inventory and item interactions.
- [ ] Small-encounter combat.
- [ ] Major-fight prototype.

## Phase 5: Story production
- [ ] Finalize chapter order.
- [ ] Break the Rangga investigation into quests.
- [ ] Define evidence discovery and validation.
- [ ] Write NPC-specific event chains.
- [ ] Add dialogue and illustrated portraits.

## Phase 6: Platform testing
- [ ] Keyboard and mouse usability.
- [ ] Android touch controls.
- [ ] Resolution and UI scaling.
- [ ] Save compatibility.
- [ ] Performance and storage checks.

## Working rule

Do not start several large systems at once. Finish, test, and document one small feature before expanding it.
